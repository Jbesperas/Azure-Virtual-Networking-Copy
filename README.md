
# Azure Virtual Networking

This repository contains my documentation for our Microsoft Azure networking practical activity.

In this activity, I practiced creating a Virtual Network (VNet), configuring public and private subnets, and setting up route tables in Azure.

I also created an Ubuntu virtual machine and connected to it using SSH.

## What I Did

- Created a resource group in Microsoft Azure
- Configured an Azure Virtual Network (VNet)
- Created public and private subnets
- Created and associated route tables
- Deployed an Ubuntu virtual machine
- Connected to the virtual machine through SSH

## Challenges I Encountered

While setting up the virtual machine, I encountered an issue with the available VM sizes and had to request a quota increase.

I also had some difficulty configuring the SSH connection, especially locating the correct file path. After asking for help and troubleshooting the problem, I was able to connect successfully.

## Results

I successfully connected to my Ubuntu virtual machine through SSH.

The screenshots of my network configurations and SSH connection are included in my documentation.
